# Expo Go Test App 🚀

Тестовое приложение на React Native и Expo (SDK 57) для проверки и демонстрации возможностей мобильной разработки через клиент **Expo Go**.

---

## 📱 Быстрый запуск для Expo Go

### 1. Установите Expo Go на телефон
- **Android**: [Google Play — Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent)
- **iOS**: [App Store — Expo Go](https://apps.apple.com/app/expo-go/id982107779)

### 2. Запустите сервер разработки
В терминале проекта выполните:

```bash
npm start
```
или
```bash
npx expo start
```

### 3. Отсканируйте QR-код
- **Android**: Откройте приложение **Expo Go** на телефоне и нажмите **«Scan QR code»**.
- **iOS**: Откройте стандартную камеру iPhone и наведите её на QR-код в терминале (или браузере), затем нажмите на баннер открытия в Expo Go.

> 💡 **Примечание**: телефон и компьютер должны находиться в одной локальной Wi-Fi сети. Если сеть изолирована или используется мобильный интернет, запустите с флагом tunnel:
> ```bash
> npx expo start --tunnel
> ```

## ✨ Что включено в приложение:

1. **Вкладка «Тесты»**:
   - **Интерактивный счётчик** (+ / - / сброс) с тактильной отдачей (вибрация).
   - **Текстовое поле с живым рендерингом** (live state updates).
   - **Тестирование нативных действий**: вызов нативного `Alert` и аппаратной вибрации устройства.
2. **Вкладка «Устройство»**:
   - Определение платформы (Android / iOS) и версии ОС.
   - Размеры экрана, соотношение сторон и плотность пикселей.
   - Версии SDK (Expo SDK 57, React 19, React Native 0.86).
3. **Вкладка «Гайд»**:
   - Советы по горячей перезагрузке (Fast Refresh).
   - Жест встряхивания (Shake) для вызова Developer Menu в Expo Go.
4. **Светлая / Тёмная тема**:
   - Переключатель темы в верхнем правом углу для проверки изменения палитры на лету.
